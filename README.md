# DictaText releases

Windows installers and verified update metadata for DictaText. Inference, dictation, dictionary, history and learning remain local.

Updates are initiated explicitly by the user. Each stable release contains an installer, SHA-256 checksums and a versioned update manifest. Installers contain no personal data or LLM GGUF model.

Voice accuracy and device behavior require physical QA; release notes distinguish automated checks from human validation.
